# API de Demonstração de Desenvolvedores

## Descrição

API desenvolvida com Java e Spring Boot para demonstrar um portfólio de desenvolvedora.

## Tecnologias

- Java 17
- Spring Boot
- Spring Web
- Spring Data JPA
- H2 Database
- Maven

## Funcionalidades

- Cadastro de perfil
- Consulta de perfil
- Cadastro de projetos
- Consulta de projetos
- Cadastro de tecnologias
- Consulta de tecnologias
